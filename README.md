## 为什么做这个项目？

大家好，我是[骆昱宇](https://luoyuyu.vip/)，香港科技大学（广州）的助理教授。从自己读博到指导学生，我反复看到一个场景：许多才华横溢的研究生，在踏入科研大门时，常常被相似的困境所困扰：

*   **理论与实践脱节**：读了再多"科研指南"，面对自己的课题时，依旧不知如何下笔。
*   **指导资源稀缺**：导师日程繁忙，无法对你萌生的每一个想法进行及时、细致的评估。
*   **投稿前的迷茫**：论文写完，却不确定逻辑是否严密、图表是否符合顶会审美、行文是否暗含"低级错误"。
*   **AI时代的"能力鸿沟"**：大模型很强大，但若缺乏判断力与学术品味，AI也只是"高级玩具"。**卓越的科研成果，无法仅靠“万能 Prompt”催生。**

这些挑战，共同构成了科研的 **"最后一公里问题" (The Last-Mile Problem)**。它不仅是方法论的缺失，更是经验、品味与判断力的综合考验。

为此，我发起了 Supervisor-Skills 项目。我们将过去十年在数据科学与人工智能顶级会议（如 SIGMOD, VLDB, ICML, NeurIPS）中积累的发表、审稿经验与学术直觉，进行"蒸馏"与"锻造"，最终封装成一套结构化的、可被大语言模型（如 Claude, GPT-4）精确执行的 **AI技能 (AI Skills)**。 我们的愿景很简单：**将资深科研者的隐性知识，转化为人人可用的 AI 工具，让 AI 成为你真正的、全天候在线的科研副导师**

这个项目仍处在早期阶段，我们正努力将自己能力范围内的认知与见解毫无保留地呈现出来，希望能为初入科研领域的探索者提供一份实用的操作指南。我们更热切地期待，能与各位同行者一起，共同建设、完善这个知识库，让科研之路不再孤单。如果你觉得这个项目对你有帮助，请点亮右上角的⭐️Star⭐️！谢谢！

|---|---|---|

| **Benchmark Paper Template** | 专为 Benchmark/Evaluation 类论文设计，辅助梳理评估逻辑和实验设计 | [使用技能](skills/benchmark-paper-template/SKILL.md) |
| **Pre-Submission Reviewer** | 顶会审稿人视角！基于写作 Checklist 和英语语法易错点，对草稿进行全面审查 | [使用技能](skills/pre-submission-reviewer/SKILL.md) |
| **Figure Design Advisor** | 告诉 AI 你想表达什么，它会根据动机图/总览图/实验图的设计范式给出专业作图建议 | [使用技能](skills/figure-designer/SKILL.md) |

## 快速开始 (Quick Start)

把下方这段 Prompt 发给你的 AI 助手（Claude Code、Cursor、Codex 等）即可完成安装：

```
Help me install Supervisor-Skills from https://github.com/HKUSTDial/Supervisor-Skills with Skills.
```

想要 Agent 原生的用法，可以装 **[Ducktor](https://github.com/HKUSTDial/Ducktor)**：它以 Supervisor-Skills 为底，做成 Claude Code、Codex 的原生插件。装好后在项目里敲一次 `/duck on`，Agent 干活时，Ducktor 把每一步背后的科研判断讲给你。用 DeepSeek Harness 的，装 **[DeepSeek-Ducktor](https://github.com/HKUSTDial/DeepSeek-Ducktor)**。把对应的一段发给 AI 助手：

```
帮我安装 Ducktor 插件：https://github.com/HKUSTDial/Ducktor
照仓库里 INSTALL.md 的步骤装好，装完告诉我怎么开始用。
```

## 🔗 相关开源项目

除了科研构思与论文写作，下面几个项目可以把这套方法带进你的 Agent，也可以帮助你进一步分析数据、呈现研究结果。

### 🎓 Ducktor 与 DeepSeek-Ducktor：Agent 原生的科研导师

Ducktor 是 Supervisor 系列的续作。Agent 替你推进研究时，Ducktor 把每一步拆开讲给你：这一步做了什么判断、常见做法和有经验的人会怎么想、什么条件下这个判断不成立。决策和带得走的原则记进项目里的 `.duck/`；敲 `/duck-learn` 复盘一段工作，敲 `/duck-why` 追问某一步为什么这样做。

<p align="center">
  <a href="https://github.com/HKUSTDial/Ducktor"><img src="https://raw.githubusercontent.com/HKUSTDial/Ducktor/main/assets/before-after.zh-CN.png" width="880" alt="示意图，不是录屏。标题：Agent 负责完成科研；Ducktor 想和你一起学习科研。同一句话：「实验都做完了，结果在 results/ 里。帮我写成一篇 NeurIPS 论文。」左边没装 Ducktor：AI 读完结果，写了 335 行 paper/main.tex，说都做完了。右边分三步：/duck-outline 讲贡献写的是「只用注意力，不用循环和卷积」，删掉这一条，论文的主张就变；/duck-write 讲基线的训练成本取自各家论文，算法可能和我们不同，所以正文写「estimated」「about 2.9×」，原则「用词的强弱，跟着证据的强弱走」记进笔记本；/duck-review 讲英德上 big 比 base 高 1.1，可参数、步数和 dropout 一起变了，这 1.1 算不到哪一处上，下次先做一组只改一处的对照。"></a>
</p>

- [Ducktor](https://github.com/HKUSTDial/Ducktor)：Claude Code 和 Codex 的插件（Codex 里命令写成 `$duck:duck-learn` 这样）；Cursor、Gemini CLI 等可以复制它的 AGENTS.md 使用。
- [DeepSeek-Ducktor](https://github.com/HKUSTDial/DeepSeek-Ducktor)：DeepSeek Harness 的原生插件，命令和规则与 Ducktor 一致。

### 📊 DataMagic：动态图表与数据故事

准备组会、论文汇报或项目演示时，可以从 DataMagic 的动态图表配方库中选择案例，通过配套的 `datamagic` Skill，将趋势、排名、对比等数据组织成动画与数据故事。

选择配方、复制实现指令，再交给 Claude Code、Cursor、Codex 等代码智能体，即可替换自己的数据并调整效果。

[GitHub 仓库](https://github.com/HKUSTDial/DataMagic)

### 🔍 DeepEye：数据分析智能体

面对文件、数据库等多种数据源，DeepEye 可以规划并执行多步骤分析工作流，生成分析报告、交互仪表盘和数据视频，支持查看执行过程并参与调整。

[GitHub 仓库](https://github.com/HKUSTDial/DeepEye)
