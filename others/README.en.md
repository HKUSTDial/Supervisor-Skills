# others

English · [中文](README.md)

This folder holds skills contributed and maintained by outside authors. The ten anchor skills live under [`skills/`](../skills/); see [skills/README.en.md](../skills/README.en.md).

- [drawio-reconstruction](drawio-reconstruction/SKILL.md): rebuilds reference images, paper figures, architecture diagrams, slide diagrams, or UI screenshots into editable `.drawio` files with PNG previews and visual audits. Adapted from [drawio-reconstruction-skill](https://github.com/sxy1499894281/drawio-reconstruction-skill), retaining the MIT License.
- [rebuttal-guidance](rebuttal-guidance/SKILL.md): based on a conditional persuasion model, identifies the reviewer's mindset (X), matches a rebuttal strategy (Y), and gives actionable response guidance for each Weakness/Question, with concern classification, tone advice, evidence pointers, and a completeness check.
