# others

[English](README.en.md) · 中文

这里是外部作者贡献、由作者维护的技能。[`skills/`](../skills/) 下的 10 个主线技能见 [skills/README.md](../skills/README.md)。

- [drawio-reconstruction](drawio-reconstruction/SKILL.md)：将参考图、论文图、架构图、幻灯片图或 UI 截图重建为可编辑 `.drawio` 文件，并导出 PNG 预览与视觉审计。改编自 [drawio-reconstruction-skill](https://github.com/sxy1499894281/drawio-reconstruction-skill)，保留 MIT License。
- [rebuttal-guidance](rebuttal-guidance/SKILL.md)：基于条件说服模型，识别审稿人心态（X）、匹配 rebuttal 策略（Y），为每条 Weakness/Question 生成可执行的回应指导，含 concern 分类、语气建议、证据指针与完整性检查。
